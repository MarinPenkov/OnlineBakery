# Sweet Heaven — онлайн сладкарница

Училищен проект за сайт на тема „Онлайн сладкарница“.

## Страници
- `index.html` — начална страница с категории, бестселъри, hero секция и падащо меню
- `category.html` — продуктова страница по категория с търсене и сортиране
- `product.html` — детайлна страница на продукт
- `cart.html` — JavaScript количка и примерна поръчка
- `about.html` — страница „За нас“

## Технологии
HTML, CSS, JavaScript, PHP, MySQL, GitHub.

## Стартиране с XAMPP
1. Копирай папката `online_sladkarnica` в `C:\xampp\htdocs\`.
2. Стартирай Apache и MySQL от XAMPP Control Panel.
3. Отвори `http://localhost/phpmyadmin`.
4. Import-ни файла `database/schema.sql`.
5. Отвори сайта: `http://localhost/online_sladkarnica/`.

## База данни
Файлът `database/schema.sql` създава база `sladkarnica` с таблици за категории, продукти, поръчки и продукти към поръчка.
